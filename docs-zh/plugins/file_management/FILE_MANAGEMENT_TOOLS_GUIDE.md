## 概述

文件管理工具插件为智能文件和文件夹组织提供了一套全面的工具，包括：

- **智能分类**：根据可配置的规则对文件夹进行分类，支持中文文本
- **批量处理**：并行处理多个文件/文件夹，并进行进度跟踪
- **文件夹合并**：智能合并重复文件夹并解决冲突
- **人工决策集成**：针对模糊场景的交互式决策
- **实验模式**：在执行前预览操作并提供详细报告
- **文本处理**：高级文本规范化和中文/拼音转换
- **模式匹配**：使用 Aho-Corasick 自动机进行高效的多模式字符串匹配

### 核心特性

✅ **工作流集成**：与 workflow-toolkit 的插件系统无缝集成  
✅ **人工参与**：针对复杂场景的交互式决策  
✅ **实验模式**：在执行前进行安全的预览和确认  
✅ **中文文本支持**：完整的 Unicode 支持及拼音转换  
✅ **批量操作**：支持可配置并发量的并行处理  
✅ **冲突解决**：多种处理文件冲突的策略  
✅ **进度跟踪**：实时进度报告和性能指标  
✅ **错误恢复**：具有回滚能力的全面错误处理

## 快速开始

### 安装

文件管理工具作为插件包含在 workflow-toolkit 系统中：

```bash
# 构建带文件管理工具的项目
cargo build --features file-management

# 验证插件是否可用
```
