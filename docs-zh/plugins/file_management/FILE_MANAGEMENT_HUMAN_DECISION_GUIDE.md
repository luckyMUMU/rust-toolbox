## 概述

在文件管理工作流中集成人工决策，弥补了自动化处理与人类判断之间的鸿沟，从而实现：

- **智能自动化**：自动处理常规任务，同时将复杂场景升级给人工处理
- **质量保证**：确保关键决策接受人工监督
- **学习系统**：通过人工反馈和模式识别改进自动化
- **灵活处理**：适应不断变化的需求和边缘情况
- **用户控制**：在重要的文件管理决策中保持用户的主动权

### 核心原则

✅ **减少决策疲劳**：对相似决策进行分组并提供智能默认值  
✅ **丰富的上下文**：提供全面的信息以支持明智的决策  
✅ **渐进式披露**：先显示必要信息，根据需求提供细节  
✅ **高效工作流**：优化决策过程以提高速度和准确性  
✅ **学习集成**：利用决策结果改进未来的自动化  
✅ **优雅降级**：优雅地处理超时和错误

## 决策点设计

### 何时引入人工决策

#### 适用场景

1. **分类结果模糊**
   - 多个类别的置信度分数相似（差异 < 0.2）
   - 所有类别的置信度分数均较低（< 0.7）
   - 不同算法给出的分类信号冲突

2. **高风险操作**
   - 大规模文件移动或删除（> 1GB 或 > 1000 个文件）
   - 影响系统或应用程序目录的操作
