## 模板概览

文件管理工具包含三个针对不同文件管理场景的综合工作流模板：

| 模板 | 目的 | 核心特性 |
|----------|---------|--------------|
| **交互式分类** | 智能文件夹组织 | 人工决策、实验模式、中文支持 |
| **交互式合并** | 重复文件夹合并 | 多种策略、冲突解决、备份 |
| **交互式批量处理** | 通用批量操作 | 并行处理、错误恢复、过滤 |

### 通用特性

所有模板都具有以下核心能力：

✅ **人工决策集成**：针对模糊场景的交互式决策  
✅ **实验模式**：在执行前预览操作并提供详细报告  
✅ **错误处理**：全面的错误恢复和回滚能力  
✅ **进度跟踪**：实时进度更新和性能指标  
✅ **可配置批处理**：可调节的批次大小和并发级别  
✅ **冲突解决**：处理文件冲突的多种策略  
✅ **审计追踪**：所有操作的完整日志记录和报告

## 交互式分类工作流

**文件**：`examples/templates/interactive-classification-workflow.yaml`

### 目的

根据可配置的规则智能分类和组织文件夹，支持人工决策和实验模式预览。

### 工作流步骤

1. **📁 扫描文件夹**：发现源目录中的所有文件夹
2. **✅ 验证规则**：验证分类规则是否有效且完整
3. **🔄 批量分类**：以可配置的批次进行并行执行，处理文件夹分类
