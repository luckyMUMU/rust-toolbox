# Rust Toolbox GUI 设计文档

## 1. 整体架构

### 1.1 组件化设计

本项目采用组件化设计，将GUI拆分为多个独立的可复用组件，便于维护和扩展。组件分为以下几类：

- **基础组件**：提供基本的UI元素
- **布局组件**：用于构建页面布局
- **导航组件**：用于实现页面导航
- **表单组件**：用于用户输入
- **数据展示组件**：用于展示数据

### 1.2 目录结构

```
rt-gui/src/components/
├── base/             # 基础组件
│   ├── button.rs     # 按钮组件

│   └── progress.rs   # 进度条组件
├── data_display/     # 数据展示组件
│   ├── card.rs       # 卡片组件
│   ├── list.rs       # 列表组件
│   ├── mod.rs        # 模块导出
│   └── table.rs      # 表格组件
├── form/             # 表单组件
│   ├── checkbox.rs      # 复选框组件

│   ├── file_input.rs    # 文件输入组件

│   ├── slider.rs        # 滑块组件

├── layout/           # 布局组件

├── navigation/       # 导航组件
```

## 2. 布局设计

### 2.1 整体布局

应用采用经典的三栏布局：

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                           顶部面板 (Top Panel)                               │
├───────────────┬─────────────────────────────────────────────────────────────┤
│               │                                                             │
│ 左侧面板      │                     中央面板 (Central Panel)                │
│ (Side Panel)  │                                                             │
│               │                                                             │
│               │                                                             │
└───────────────┴─────────────────────────────────────────────────────────────┘
```

### 2.2 顶部面板 (Top Panel)

- **高度**: 60px
- **内容**:
  - 左侧：应用Logo和名称
  - 右侧：语言选择器
- **实现**: `render_top_panel` 方法

### 2.3 左侧面板 (Side Panel)

- **宽度**: 250px（可调整）
- **内容**:
  - 工具分类列表
  - 工具选择
- **实现**: `render_left_panel` 方法

### 2.4 中央面板 (Central Panel)

- **内容**:
  - 标签页栏
  - 工具内容区域
  - 输入表单
  - 输出结果
- **实现**: `render_central_panel` 方法

## 4. 交互设计

### 4.1 标签页管理

- **新建标签页**: 点击"新建标签页"按钮
- **切换标签页**: 点击标签页标题
- **关闭标签页**: 点击标签页上的关闭按钮

### 4.2 工具使用流程

1. 从左侧面板选择工具
2. 在输入表单中填写参数
3. 点击"运行"按钮执行工具
4. 在输出区域查看结果

### 4.3 消息处理

- **异步处理**: 工具运行采用异步方式，避免阻塞UI
- **消息通信**: 使用 `mpsc` 通道进行UI与异步任务的通信
- **状态更新**: 工具运行状态实时更新到UI

## 5. 样式设计

### 5.1 色彩方案

- **主色调**: 蓝色系 (#4A90E2)
- **成功状态**: 绿色系 (#50E3C2)
- **警告状态**: 黄色系 (#FFA500)
- **错误状态**: 红色系 (#FF5252)
- **中性色**: 灰色系

### 5.2 字体设计

- **标题字体**: 较大字号，加粗
- **正文字体**: 中等字号
- **辅助文本**: 较小字号，浅色

### 5.3 间距设计

- **组件间距**: 统一的组件间距，确保界面整洁
- **内部间距**: 合理的内部间距，确保内容易读
- **布局间距**: 合理的布局间距，确保区域清晰

## 6. 国际化设计

- **支持语言**: 英语 (En) 和中文 (Zh)
- **实现**: 使用 `Locale` 枚举和翻译映射
- **切换方式**: 通过顶部面板的语言选择器切换
- **应用范围**: 所有UI文本和工具描述

## 7. 插件系统

- **功能**: 支持动态加载插件工具
- **实现**: 使用 `PluginManager` 管理插件
- **加载方式**: 启动时自动加载 `plugins` 目录下的插件
- **集成方式**: 插件工具与内置工具统一管理

## 8. 性能优化
