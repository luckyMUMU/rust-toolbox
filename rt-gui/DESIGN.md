# 模块名称：Rust Toolbox GUI

## 1. 目标 (Goal)
- **核心功能**：为 Rust Toolbox 提供直观、易用的图形用户界面，支持工具选择、参数配置、执行控制和结果展示。
- **非目标**：不包含工具的具体实现，不处理命令行参数，不包含核心业务逻辑。

## 2. 核心定义 (Definitions)
- **LayoutManager**：布局管理器，负责管理不同的布局类型（单栏、双栏、三栏）。
- **TabNav**：标签页导航组件，负责标签页的创建、切换和关闭。
- **Sidebar**：侧边栏组件，负责工具分类和选择。
- **ToolUI**：工具UI组件，负责动态生成工具的输入表单和结果展示。
- **AppState**：应用状态管理，包含当前选中的工具、布局类型、语言设置等。

## 3. 算法与逻辑设计 (Algorithm & Logic)

### 核心流程
1. **应用初始化**：
   - 加载应用配置。
   - 初始化布局管理器。
   - 加载工具列表。
   - 渲染初始界面。

2. **工具选择流程**：
   - 用户从左侧面板选择工具分类。
   - 显示该分类下的工具列表。
   - 用户选择具体工具。
   - 动态生成工具的输入表单。

3. **工具执行流程**：
   - 用户填写工具参数。
   - 点击"运行"按钮触发工具执行。
   - 异步执行工具，避免阻塞UI。
   - 实时更新执行状态。
   - 显示执行结果。

4. **布局管理**：
   - 支持三种布局类型：单栏、双栏、三栏。
   - 允许用户在运行时切换布局。
   - 保存用户的布局偏好。

### 架构组件

#### 组件化设计
项目采用组件化设计，将GUI拆分为多个独立的可复用组件，便于维护和扩展。组件分为以下几类：
- **基础组件**：提供基本的UI元素
- **布局组件**：用于构建页面布局
- **导航组件**：用于实现页面导航
- **表单组件**：用于用户输入
- **数据展示组件**：用于展示数据

### 布局设计

#### 整体布局
应用采用经典的三栏布局：
```
┌───────────────────────────────────────────────────────────────────────────────┐
│                           顶部面板 (Top Panel)                               │
├───────────────┬─────────────────────────────────────────────────────────────┤
│               │                                                             │
│ 左侧面板      │                     中央面板 (Central Panel)                │
│ (Side Panel)  │                                                             │
│               │                                                             │
│               │                                                             │
└───────────────┴─────────────────────────────────────────────────────────────┘
```

#### 顶部面板 (Top Panel)
- **高度**: 60px
- **内容**:
  - 左侧：应用Logo和名称
  - 右侧：语言选择器
- **实现**: `render_top_panel` 方法

#### 左侧面板 (Side Panel)
- **宽度**: 250px（可调整）
- **内容**:
  - 工具分类列表
  - 工具选择
- **实现**: `render_left_panel` 方法

#### 中央面板 (Central Panel)
- **内容**:
  - 标签页栏：支持标签页的创建、切换、关闭、拖拽排序和未读状态指示
  - 工具内容区域：支持多种布局类型（单栏、双栏、三栏）
  - 输入表单
  - 输出结果
- **实现**: `render_central_panel` 方法

#### 布局类型
- **单栏布局**: 输入区域在上，输出区域在下
- **双栏布局**: 左侧输入，右侧输出（默认）
- **三栏布局**: 左侧输入，中间预览，右侧输出

### 交互设计

#### 标签页管理
- **新建标签页**: 点击"新建标签页"按钮
- **切换标签页**: 点击标签页标题
- **关闭标签页**: 点击标签页上的关闭按钮

#### 工具使用流程
1. 从左侧面板选择工具
2. 在输入表单中填写参数
3. 点击"运行"按钮执行工具
4. 在输出区域查看结果

#### 消息处理
- **异步处理**: 工具运行采用异步方式，避免阻塞UI
- **消息通信**: 使用 `mpsc` 通道进行UI与异步任务的通信
- **状态更新**: 工具运行状态实时更新到UI

## 4. 接口与边界 (Interface & Boundary)

### 组件接口

#### LayoutManager
```rust
impl LayoutManager {
    pub fn new() -> Self; // 创建布局管理器
    pub fn switch_layout(&mut self, layout_type: LayoutType); // 切换布局类型
    pub fn get_current_layout(&self) -> LayoutType; // 获取当前布局类型
    pub fn render(&self, app_state: &AppState) -> Element; // 渲染布局
}
```

```rust
impl TabNav {

    pub fn close_tab(&mut self, tab_index: usize); // 关闭标签页

```
