## 1. 项目愿景

Workflow Toolkit 是一个**工具能力编排与复用平台**，通过对工具的工作流编排实现固定流程的复用，支持 AGENT 动态扩展能力构建复杂功能，同时提供 CLI/TUI 接口让人类用户便捷调用并监测运行状况。

### 1.1 核心价值主张

| 价值维度 | 描述 |
|----------|------|
| **工具编排复用** | 工作流编排固化流程，一次定义，多次复用，降低重复开发成本 |
| **AGENT 能力扩展** | 动态编排让 AGENT 突破单工具限制，支持工具组合构建复杂函数效果 |
| **人机双模式** | AGENT 模式（MCP 协议）+ 人类模式（CLI/TUI），统一工具发现和使用体验 |
| **开发者友好** | 脚本化编排（YAML/JSON）、多语言插件 SDK、开放基础设施能力 |
| **高性能** | Rust + Tokio 异步运行时，微秒级调度延迟，单机支持 100+ 并发工作流 |
| **模块化** | 核心引擎与业务逻辑分离，插件化架构，DDD 分层设计 |
| **可靠性** | 内置检查点与自动重试，事务性状态管理，全面的审计日志 |
| **AI 就绪** | MCP 协议原生支持，上下文管理与 Token 计数，流式响应支持 |

## 2. 项目范围

### 2.1 包含内容 (In Scope)

- ✅ 工作流引擎（DAG 定义、调度、执行）
- ✅ 多类型插件系统（Native/Python/Node.js/Docker/WASM）
- ✅ 工具注册与执行系统
- ✅ 三接口支持（CLI、TUI、MCP Server）
- ✅ 脚本化工作流定义（YAML/JSON）
- ✅ 存储与缓存基础设施
- ✅ 性能监控与优化
- ✅ 检查点与重试机制
- ✅ 事务管理
- ✅ 安全沙箱隔离

### 2.2 不包含内容 (Out of Scope)

- ❌ 分布式执行（当前为单机版本）
- ❌ 图形化工作流编辑器（未来扩展）
- ❌ 云原生部署（当前为本地部署）
- ❌ 工作流市场（未来扩展）

## 5. 项目约束

### 5.1 技术约束

- **编程语言**: Rust（核心系统）
- **异步运行时**: Tokio
- **操作系统**: Windows、Linux、macOS
- **架构模式**: DDD 分层架构
- **文档规范**: AGENT_SOP.md 定义的 Spec-first 工作流

### 5.2 质量约束

- **安全**: 严禁硬编码密钥，所有外部输入必须验证
- **性能**: API 响应时间 < 500ms
- **代码**: 严禁使用 unwrap/expect（除测试外）
- **文档**: 中文注释，先写规范后写代码

### 5.3 时间约束

- **第一阶段**（2026-01 ~ 2026-02）: 核心引擎实现
- **第二阶段**（2026-02 ~ 2026-03）: 插件系统完善
- **第三阶段**（2026-03 ~ 2026-04）: 接口优化与文档完善
