# Workflow Toolkit 需求规范

> **规范层级**: P1 级（系统级规范）
> **约束强度**: 跨模块约束，需技术负责人审批

---

## 概述

本文档定义 Workflow Toolkit 系统的功能需求、业务规则和验收标准。所有需求使用 BDD 场景描述，确保可测试性和可追溯性。

## 核心需求

### Requirement: 工作流引擎核心能力

系统 SHALL 提供 DAG 结构的工作流编排能力，支持节点间数据传递和并行执行。

**业务规则**:

| 规则ID | 规则描述 | 验证方法 | 优先级 | 异常处理 |
|--------|----------|----------|--------|----------|
| BR-W001 | 工作流定义必须符合 DAG 结构，禁止循环依赖 | DAG 拓扑排序检测，时间复杂度 O(V+E) | P0 | 返回错误信息，指出循环路径中的节点列表 |
| BR-W002 | 节点 ID 必须符合 `^[a-zA-Z][a-zA-Z0-9_-]*$` 格式 | 正则表达式验证，长度限制 1-64 字符 | P0 | 返回格式错误提示，说明正确格式要求 |
| BR-W003 | 工作流执行支持暂停、恢复和取消操作 | 状态机验证，支持 Running/Paused/Cancelled 状态转换 | P1 | 记录操作日志，状态持久化到检查点文件 |
| BR-W004 | 节点执行超时默认 30 秒，可配置范围 1s-3600s | 超时检测机制，使用 tokio::time::timeout | P1 | 超时后按重试策略处理，记录超时事件 |
| BR-W005 | 工作流最大节点数 1000，单节点输出数据≤10MB | 配置验证，启动时检查配置合法性 | P2 | 超出时拒绝创建，返回资源限制提示 |
| BR-W006 | 并行节点数不超过配置的最大并发数（默认 CPU 核心数） | 信号量控制并发数 | P1 | 超出时排队等待，记录等待时间 |

#### Scenario: 创建有效 DAG 工作流
- **GIVEN** 用户已定义工作流脚本
- **AND** 脚本符合 YAML/JSON 格式规范
- **WHEN** 用户提交工作流定义
- **THEN** 系统验证 DAG 结构有效
- **AND** 工作流成功注册到系统

#### Scenario: 拒绝循环依赖工作流
- **GIVEN** 用户定义了包含循环依赖的工作流
- **WHEN** 用户提交工作流定义
- **THEN** 系统拒绝注册
- **AND** 返回明确的错误信息指出循环路径

#### Scenario: 节点间数据传递
- **GIVEN** 工作流包含节点 A 和节点 B
- **AND** 节点 B 依赖节点 A 的输出
- **WHEN** 工作流执行
- **THEN** 节点 B 能够获取节点 A 的输出数据
- **AND** 数据格式正确传递

#### Scenario: 并行节点执行
- **GIVEN** 工作流包含多个无依赖关系的节点
- **AND** 配置最大并发数为 N
- **WHEN** 工作流执行
- **THEN** 无依赖节点并行执行
- **AND** 并发数不超过配置的最大值

#### Scenario: 工作流执行重试
- **GIVEN** 节点配置了重试策略
- **AND** 节点执行失败
- **WHEN** 系统检测到失败
- **THEN** 按照指数退避策略自动重试
- **AND** 记录重试日志

#### Scenario: 工作流暂停与恢复
- **GIVEN** 工作流正在执行中
- **WHEN** 用户请求暂停工作流
- **THEN** 工作流在当前节点完成后暂停
- **AND** 状态持久化保存
- **WHEN** 用户请求恢复工作流
- **THEN** 工作流从暂停点继续执行

#### Scenario: 节点执行超时（关键异常）
- **GIVEN** 节点配置了执行超时时间
- **AND** 节点执行时间超过配置的超时时间
- **WHEN** 系统检测到超时
- **THEN** 系统取消节点执行
- **AND** 按重试策略处理或标记失败
- **AND** 记录超时事件到日志

#### Scenario: 节点输出数据过大（关键异常）
- **GIVEN** 节点执行产生输出数据
- **AND** 输出数据大小超过 10MB 限制
- **WHEN** 节点尝试返回输出
- **THEN** 系统拒绝输出
- **AND** 返回数据大小超限错误
- **AND** 建议使用存储接口存储大数据

### Requirement: 插件系统

系统 SHALL 支持多语言插件（Rust/Python/Node.js），并提供沙箱隔离执行环境。

**业务规则**:

| 规则ID | 规则描述 | 验证方法 | 优先级 | 异常处理 |
|--------|----------|----------|--------|----------|
| BR-P001 | 插件必须在沙箱中执行，资源使用受限 | WASM/Wasmtime 沙箱隔离，资源配额验证 | P0 | 拒绝加载，返回沙箱配置错误 |
| BR-P002 | 插件网络访问默认关闭，需显式授权 | 网络权限配置检查，Capability-based 安全模型 | P0 | 阻止网络请求，记录安全审计日志 |
| BR-P003 | 插件依赖自动管理，支持版本锁定 | 依赖解析器，Cargo/Pip/Npm 锁文件验证 | P1 | 依赖冲突时提示用户选择版本 |
| BR-P004 | 单插件内存限制 512MB，CPU 时间限制可配置 | cgroups/资源监控，超限自动终止 | P0 | 终止插件进程，返回资源超限错误 |
| BR-P005 | 插件热重载不影响正在执行的任务 | 引用计数 + 优雅关闭，等待任务完成 | P1 | 延迟重载，记录重载事件 |
| BR-P006 | 插件必须声明所需权限，最小权限原则 | 权限清单验证，启动时检查权限声明 | P0 | 权限不足时拒绝执行，返回权限错误 |

#### Scenario: 加载 Rust 原生插件
- **GIVEN** Rust 插件已编译并安装到插件目录
- **AND** 插件符合 Native SDK 规范
- **WHEN** 系统加载插件
- **THEN** 插件初始化成功
- **AND** 插件工具注册到工具注册表

#### Scenario: 加载 Python 插件
- **GIVEN** Python 插件已安装到插件目录
- **AND** 插件符合 Python SDK 规范
- **WHEN** 系统加载插件
- **THEN** 插件在沙箱环境中初始化
- **AND** 插件工具注册到工具注册表

#### Scenario: 加载 Node.js 插件
- **GIVEN** Node.js 插件已安装到插件目录
- **AND** 插件符合 Node.js SDK 规范
- **WHEN** 系统加载插件
- **THEN** 插件在沙箱环境中初始化
- **AND** 插件工具注册到工具注册表

#### Scenario: 插件沙箱隔离
- **GIVEN** 插件在沙箱中执行
- **WHEN** 插件尝试访问受限资源（如文件系统敏感路径）
- **THEN** 系统拒绝访问
- **AND** 记录安全审计日志

#### Scenario: 插件资源限制
- **GIVEN** 插件配置了资源限制（CPU/内存）
- **WHEN** 插件执行超过资源限制
- **THEN** 系统终止插件执行
- **AND** 返回资源超限错误

#### Scenario: 插件热重载
- **GIVEN** 插件已加载运行中
- **WHEN** 插件文件更新
- **THEN** 系统检测到变更
- **AND** 自动重新加载插件
- **AND** 不影响正在执行的任务

#### Scenario: 插件权限不足（关键异常）
- **GIVEN** 插件尝试执行需要权限的操作
- **AND** 插件未声明该权限
- **WHEN** 插件执行操作
- **THEN** 系统拒绝执行
- **AND** 返回权限不足错误
- **AND** 记录安全审计日志

#### Scenario: 插件加载失败（关键异常）
- **GIVEN** 插件文件存在但格式错误
- **WHEN** 系统尝试加载插件
- **THEN** 系统拒绝加载
- **AND** 返回加载失败原因
- **AND** 不影响其他插件正常运行

### Requirement: 多接口支持

系统 SHALL 提供 CLI、TUI、MCP 三种接口，满足不同用户场景。

**业务规则**:

| 规则ID | 规则描述 | 验证方法 | 优先级 | 异常处理 |
|--------|----------|----------|--------|----------|
| BR-I001 | CLI 命令参数必须经过验证和转义 | 参数解析器 + shell 转义处理 | P0 | 拒绝执行，返回参数错误 |
| BR-I002 | TUI 刷新率不低于 30fps，响应时间<100ms | 帧率监控 + 性能计数器 | P1 | 降级显示，记录性能警告 |
| BR-I003 | MCP 连接需要认证，支持 Token 和 API Key | 认证中间件，Token 验证 | P0 | 拒绝连接，返回认证失败 |
| BR-I004 | MCP 单连接最大并发请求数 100 | 并发计数器，信号量控制 | P1 | 超出时排队等待，返回队列位置 |
| BR-I005 | CLI 输出支持 JSON/Table/Plain 三种格式 | 格式化器验证，输出模板 | P2 | 默认使用 Table 格式 |

#### Scenario: CLI 执行工作流
- **GIVEN** 用户通过命令行访问系统
- **AND** 工作流已定义
- **WHEN** 用户执行 `workflow run <workflow_id>`
- **THEN** 工作流开始执行
- **AND** 实时显示执行进度
- **AND** 返回执行结果

#### Scenario: CLI 管理插件
- **GIVEN** 用户通过命令行访问系统
- **WHEN** 用户执行 `plugin install <plugin_path>`
- **THEN** 插件安装成功
- **AND** 插件工具可用

#### Scenario: TUI 监控系统状态
- **GIVEN** 用户打开 TUI 界面
- **WHEN** 用户进入监控仪表盘
- **THEN** 显示系统资源使用情况（CPU/内存/磁盘）
- **AND** 显示工作流执行状态
- **AND** 实时更新数据

#### Scenario: TUI 工作流管理
- **GIVEN** 用户在 TUI 工作流列表界面
- **WHEN** 用户选择一个工作流
- **THEN** 显示工作流详情
- **AND** 支持暂停、恢复、取消操作

#### Scenario: MCP 工具发现
- **GIVEN** AI Agent 通过 MCP 协议连接系统
- **WHEN** Agent 请求工具列表
- **THEN** 返回可用工具清单
- **AND** 包含工具描述和参数 Schema

#### Scenario: MCP 工具执行
- **GIVEN** AI Agent 选择要执行的工具
- **AND** 提供正确的参数
- **WHEN** Agent 调用工具
- **THEN** 工具执行并返回结果
- **AND** 结果格式符合 MCP 协议规范

#### Scenario: MCP 上下文管理
- **GIVEN** AI Agent 需要管理执行上下文
- **WHEN** Agent 请求上下文操作
- **THEN** 系统提供上下文存储和检索能力
- **AND** 支持 Token 计数

#### Scenario: MCP 认证失败（关键异常）
- **GIVEN** AI Agent 尝试连接系统
- **AND** 提供的 Token 或 API Key 无效
- **WHEN** Agent 请求建立连接
- **THEN** 系统拒绝连接
- **AND** 返回认证失败错误
- **AND** 记录认证失败事件

#### Scenario: CLI 参数注入攻击（关键异常）
- **GIVEN** 用户通过 CLI 执行命令
- **AND** 参数包含恶意注入代码
- **WHEN** 系统解析参数
- **THEN** 系统检测到注入攻击
- **AND** 拒绝执行命令
- **AND** 返回参数非法错误

### Requirement: 工具系统

系统 SHALL 提供工具注册、版本管理和参数验证能力。

**业务规则**:

| 规则ID | 规则描述 | 验证方法 | 优先级 | 异常处理 |
|--------|----------|----------|--------|----------|
| BR-T001 | 工具 ID 必须全局唯一，格式为 `namespace/tool-name` | 注册表唯一性检查，命名空间分隔符验证 | P0 | 拒绝注册，返回 ID 冲突错误 |
| BR-T002 | 工具必须定义参数 Schema（JSON Schema 格式） | Schema 完整性验证，必填字段检查 | P0 | 拒绝注册，返回 Schema 缺失错误 |
| BR-T003 | 工具输出必须符合定义的输出格式 | 输出 Schema 验证，运行时类型检查 | P0 | 返回输出格式错误，记录异常日志 |
| BR-T004 | 工具版本遵循 SemVer 规范，支持多版本共存 | 版本号格式验证，版本兼容性检查 | P1 | 版本冲突时提示用户选择版本 |
| BR-T005 | 工具调用超时默认 60 秒，可配置 | 超时检测机制，异步取消支持 | P1 | 超时后取消执行，返回超时错误 |
| BR-T006 | 工具参数验证失败返回中文错误信息 | JSON Schema 验证 + 中文错误消息映射 | P1 | 返回具体字段错误和修复建议 |

#### Scenario: 工具注册
- **GIVEN** 插件定义了工具接口
- **WHEN** 插件加载完成
- **THEN** 工具注册到全局注册表
- **AND** 工具可通过名称查找

#### Scenario: 工具参数验证成功
- **GIVEN** 工具定义了参数 Schema
- **AND** 用户提供了有效参数
- **WHEN** 用户调用工具
- **THEN** 参数验证通过
- **AND** 工具正常执行

#### Scenario: 工具参数验证失败
- **GIVEN** 工具定义了参数 Schema
- **AND** 用户提供了无效参数
- **WHEN** 用户调用工具
- **THEN** 系统拒绝执行
- **AND** 返回明确的中文错误信息

#### Scenario: 工具版本管理
- **GIVEN** 工具有多个版本
- **WHEN** 用户查询工具
- **THEN** 返回可用版本列表
- **AND** 支持指定版本调用

#### Scenario: 工具 ID 冲突（关键异常）
- **GIVEN** 插件尝试注册工具
- **AND** 工具 ID 已存在于注册表
- **WHEN** 系统验证工具 ID
- **THEN** 系统拒绝注册
- **AND** 返回 ID 冲突错误
- **AND** 提示使用不同的命名空间

#### Scenario: 工具调用超时（关键异常）
- **GIVEN** 用户调用工具
- **AND** 工具执行时间超过配置的超时时间
- **WHEN** 系统检测到超时
- **THEN** 系统取消工具执行
- **AND** 返回超时错误
- **AND** 释放相关资源

### Requirement: 文件管理插件

系统 SHALL 提供文件智能分类工具，支持人工确认节点。

**业务规则**:

| 规则ID | 规则描述 | 验证方法 | 优先级 | 异常处理 |
|--------|----------|----------|--------|----------|
| BR-F001 | 文件路径必须规范化，禁止路径遍历攻击 | 路径规范化 + 边界检查，禁止 `..` 和绝对路径跳转 | P0 | 拒绝访问，返回路径非法错误 |
| BR-F002 | 批量处理文件数上限 10000，单文件大小≤100MB | 文件计数器 + 大小检查 | P1 | 超出时分批处理，返回分批提示 |
| BR-F003 | 分类规则支持正则表达式和通配符 | 规则语法验证，预编译正则 | P1 | 规则错误时返回语法错误和位置 |

### Requirement: 基础设施开放接口

系统 SHALL 向插件开放存储、缓存、配置、日志等基础设施接口。

#### Scenario: 插件使用缓存接口
- **GIVEN** 插件需要缓存数据
- **WHEN** 插件调用缓存 API
- **THEN** 数据缓存成功
- **AND** 支持过期时间设置

#### Scenario: 插件使用配置接口
- **GIVEN** 插件需要读取配置
- **WHEN** 插件调用配置 API
- **THEN** 返回配置值
- **AND** 支持默认值设置

#### Scenario: 存储配额超限（关键异常）
- **GIVEN** 插件尝试存储数据
- **AND** 插件存储空间已达到 1GB 上限
- **WHEN** 插件调用存储 API
- **THEN** 系统拒绝写入
- **AND** 返回配额超限错误
- **AND** 建议清理历史数据

#### Scenario: 数据加密失败（关键异常）
- **GIVEN** 插件尝试存储敏感数据
- **AND** 系统加密服务不可用
- **WHEN** 插件调用存储 API
- **THEN** 系统拒绝存储
- **AND** 返回安全错误
- **AND** 记录安全事件
