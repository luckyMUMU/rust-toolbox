## 1. 架构概述

### 1.1 架构风格

Workflow Toolkit 采用以下架构风格：
- **分层架构**: 领域层、应用层、基础设施层、接口层
- **领域驱动设计 (DDD)**: 聚合、实体、值对象、领域服务
- **插件化架构**: 可扩展的插件系统
- **事件驱动架构**: 领域事件和事件总线

### 1.2 架构目标

1. **高性能**: 使用 Rust 的零成本抽象和并发原语
2. **可扩展**: 插件化架构支持多种插件类型
3. **可维护**: 清晰的分层和模块边界
4. **可测试**: 依赖倒置便于单元测试
5. **可观测**: 完整的指标、追踪、日志系统

### 2.2 层次职责

| 层次 | 职责 | 依赖 |
|------|------|------|
| 接口层 | 处理用户输入输出，提供多种界面 | 应用层、领域层 |
| 应用层 | 协调领域层完成用例，处理事务 | 领域层 |
| 领域层 | 核心业务逻辑，领域模型 | 无（纯净） |
| 基础设施层 | 技术实现，持久化，外部服务 | 领域层（实现接口） |

- 支持失败快速终止
