# docs/ - Documentation

## OVERVIEW
Comprehensive documentation for users, developers, and contributors.

### User Documentation
- **USER_MANUAL.md**: Complete user guide with tutorials
- **API_REFERENCE.md**: Detailed API documentation
- **FILE_MANAGEMENT_TOOLS_GUIDE.md**: File operations

### Developer Documentation
- **DEVELOPMENT_GUIDE.md**: Setup and contribution guidelines
- **PLUGIN_DEVELOPMENT.md**: Creating custom plugins
- **ARCHITECTURE.md**: System design (if exists)

### Design Documents
- **DESIGN.md**: Architecture and design decisions
- **README.md**: Project overview (root)
