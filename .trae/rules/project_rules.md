# Workflow Toolkit 项目规范

## 默认上下文加载

本项目默认加载以下 SOP 文档作为 AI 工作流的核心指导：

- **SOP 入口文档**: [AGENT_SOP.md](../../sop/AGENT_SOP.md)

> **重要**: AI 助手在处理本项目任务时，应首先阅读并遵循 `sop/AGENT_SOP.md` 中定义的工作流程、约束和 Skill 调用规则。

## 核心约束摘要

1. 先标记 `[DIR_WORKING]`，再改代码
2. 各 Skill 只操作合约范围（Scope）
3. 先复用→改进→新建→清理
4. 实现类 Skill 按目录工作：以 design.md 所在目录为工作范围
5. 自底向上并行：按目录深度从深到浅并行执行
6. 无出处不决断：无法追溯到既定依据的判断须询问用户

## 路径选择

| 任务类型 | 推荐路径 |
|---------|---------|
| 单文件、小改动（<30行） | 快速路径 |
| 跨文件、新功能、重构 | 深度路径 |
| 核心业务、复杂逻辑 | TDD 路径 |

详细工作流参见 [AGENT_SOP.md](../../sop/AGENT_SOP.md)。
