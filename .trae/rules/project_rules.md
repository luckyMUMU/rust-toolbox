# Workflow Toolkit 项目规范

## 核心约束

### DDD 规范
- **实体**: 有唯一标识，相等性基于 id，封装业务逻辑
- **值对象**: 不可变，相等性基于属性，方法返回新实例
- **聚合根**: 聚合唯一入口，维护一致性，包含乐观锁版本
- **依赖方向**: interfaces → application → domain，禁止反向依赖

### SPEC 约束
- **架构**: 严禁跨层调用，领域层不依赖其他层
- **错误**: 严禁 unwrap/expect，错误消息中文
- **性能**: 并行用 tokio::spawn，默认并发数 4
- **安全**: 输入验证，文件路径规范化，插件沙箱化

### 审查清单
- [ ] 违反分层架构或 DDD 规范
- [ ] 存在 unwrap/expect
- [ ] 错误消息非中文
- [ ] 外部输入未验证
