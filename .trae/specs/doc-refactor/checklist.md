# Checklist

## 需求文档重构验证

- [ ] 系统规范（P1 级）包含所有核心功能需求
- [ ] 系统规范包含明确的功能边界定义（包含/不包含）
- [ ] 系统规范包含核心业务流程描述
- [ ] 系统规范包含外部接口定义（CLI/TUI/MCP）
- [ ] 系统规范包含性能指标（响应时间、吞吐量、可用性）
- [ ] BDD 场景覆盖所有用户故事
- [ ] BDD 场景使用正确的 Gherkin 语法
- [ ] 质量约束（P1/P2 级）覆盖所有非功能需求

## 设计文档重构验证

- [ ] 主设计文档（P1 级）包含系统架构概述
- [ ] 主设计文档包含技术选型和 ADR 引用
- [ ] 各层设计文档（P2 级）包含模块边界定义
- [ ] 各层设计文档包含接口定义
- [ ] 各层设计文档包含依赖关系图
- [ ] 实现细节文档（P3 级）包含关键算法
- [ ] 实现细节文档包含错误处理策略
- [ ] 所有设计文档包含版本号
- [ ] 所有设计文档包含最后审核日期
- [ ] 设计文档追溯到对应的需求规范

## ADR 文档重构验证

- [ ] 所有 ADR 使用统一的 SOP 模板格式
- [ ] 所有 ADR 包含决策状态（Proposed/Accepted/Deprecated）
- [ ] 所有 ADR 包含背景、决策、理由、后果
- [ ] 所有 ADR 包含替代方案分析
- [ ] 所有 ADR 有唯一的编号（ADR-XXX）
- [ ] 所有 ADR 包含版本历史
- [ ] ADR 追溯到对应的架构原则
- [ ] ADR 索引文档完整且链接有效

## 文档清理验证

- [ ] 旧 PRD 文档已移动到归档目录
- [ ] 旧设计文档已移动到归档目录
- [ ] 旧 ADR 文档已移动到归档目录
- [ ] 所有交叉引用已更新
- [ ] 无孤立的文档文件
- [ ] 归档目录结构清晰

## 文档索引验证

- [ ] SOP 标准文档导航体系已建立
- [ ] sop/02_specifications/index.md 包含所有规范索引
- [ ] 快速导航文档（README）清晰易用
- [ ] 所有内部链接有效（无 404）
- [ ] 所有外部链接有效
- [ ] 文档目录结构符合 SOP 规范

## 整体验证

- [ ] 所有文档符合 SOP v3.0.0 规范格式
- [ ] 文档追溯关系完整（需求→设计→ADR）

- [ ] 验证报告已创建并包含所有检查结果
