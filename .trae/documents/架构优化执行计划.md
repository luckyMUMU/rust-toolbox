# Workflow Toolkit 架构优化执行计划

## 1. 计划概述

### 1.1 目标

基于架构分析报告，分三个阶段实施 23 项优化改进，提升系统的可维护性、扩展性和可靠性。

### 1.2 执行原则

1. **渐进式改进**: 保持向后兼容，分阶段迁移
2. **测试驱动**: 每项改进必须有对应测试
3. **文档同步**: 代码变更同步更新设计文档
4. **SPEC 合规**: 严格遵守 `docs/参考/SPEC.md` 规范

### 1.3 总体时间表

| 阶段 | 周期 | 工时 | 核心目标 |
|------|------|------|---------|
| P0 紧急 | 第 1-2 周 | 32h | 修复关键缺陷 |
| P1 重要 | 第 3-4 周 | 96h | 完善核心功能 |
| P2 改进 | 第 5-6 周 | 72h | 增强扩展能力 |

| 3 | 修改 `record_failure` 增加连续失败 | `src/workflow/circuit_breaker.rs` | 1h |
| 4 | 更新单元测试 | `src/workflow/circuit_breaker.rs` | 1h |

**代码变更**:

```rust
// src/workflow/circuit_breaker.rs
pub struct CircuitBreakerMetrics {
    success_count: AtomicU32,
    failure_count: AtomicU32,
    consecutive_failures: AtomicU32,  // 新增
    state_change_count: AtomicU32,
}

impl CircuitBreakerMetrics {
    pub fn record_success(&self) {
        self.success_count.fetch_add(1, Ordering::Relaxed);
        self.consecutive_failures.store(0, Ordering::Relaxed);  // 重置
    }

    pub fn record_failure(&self) {
        self.failure_count.fetch_add(1, Ordering::Relaxed);
        self.consecutive_failures.fetch_add(1, Ordering::Relaxed);  // 增加
    }
}
```

**验收标准**:

| 2 | 实现 `load_plugin_async` | `src/plugins/manager.rs` | 3h |
| 3 | 实现 `unload_plugin_async` | `src/plugins/manager.rs` | 2h |
| 4 | 保留同步方法作为兼容层 | `src/plugins/manager.rs` | 2h |
| 5 | 更新单元测试 | `src/plugins/manager.rs` | 2h |
| 6 | 更新设计文档 | `src/plugins/design.md` | 1h |

**代码变更**:

```rust
// src/plugins/manager.rs
pub struct PluginManager {
    plugins: DashMap<String, Box<dyn Plugin>>,  // 改为 DashMap
    plugin_configs: DashMap<String, PluginConfig>,
    runtime_manager: RuntimeManager,
    tool_registry: Option<Arc<ToolRegistry>>,
}

impl PluginManager {
    /// 异步加载插件（新方法）
    pub async fn load_plugin_async(
        &self,
        plugin: Box<dyn Plugin>,
        config: PluginConfig,
    ) -> Result<()> { ... }
    
    /// 同步加载插件（兼容层）
    pub fn load_plugin(&self, plugin: Box<dyn Plugin>, config: PluginConfig) -> Result<()> {
        tokio::task::block_in_place(|| {
            tokio::runtime::Handle::current().block_on(
                self.load_plugin_async(plugin, config)
            )
        })
    }
}
```
