## 一、项目概览

### 1.1 项目基本信息

| 项目属性 | 值 |
|---------|---|
| 项目名称 | Workflow Toolkit |
| 版本 | 0.1.0 |

### 1.2 项目定位

Workflow Toolkit 是一个基于 Rust 的多接口工作流执行系统，核心特性：
- **多接口支持**: CLI、TUI、MCP Server
- **多语言插件**: Native、Python、Node.js、Docker、WASM
- **DAG 工作流**: 支持复杂依赖关系和并行执行
- **高可用设计**: 检查点、重试、熔断、限流

## 三、核心模块详细分析

### 3.1 工作流引擎 (workflow/)

**架构特点**: LiteFlow 风格组件化设计

```
workflow/
├── engine.rs          # 主引擎入口
├── scheduler.rs       # DAG 调度器
├── component/         # 组件系统
│   ├── registry.rs    # 组件注册表
│   ├── tool.rs        # 工具组件
│   └── parallel.rs    # 并行组件
├── executor/          # 执行器链
│   ├── basic.rs       # 基础执行器
│   ├── retry.rs       # 重试执行器
│   ├── cache.rs       # 缓存执行器
│   └── audit.rs       # 审计执行器
├── state/             # 状态管理
│   ├── checkpoint.rs  # 检查点管理
│   └── checkpoint_recovery.rs  # 检查点恢复
├── context/           # 数据上下文
│   ├── slot.rs        # 槽位系统
│   └── mod.rs         # 上下文管理
├── parallel_executor.rs  # JoinSet 并行执行
├── flow_control.rs    # 流程控制(Switch/Loop)
├── backpressure.rs    # 背压控制
├── circuit_breaker.rs # 熔断器
└── rate_limiter.rs    # 限流器
```

**关键设计模式**:
- **责任链模式**: ExecutorChain 处理横切关注点
- **策略模式**: 不同的执行策略（重试、缓存、审计）
- **观察者模式**: ExecutionTracker 状态追踪

### 3.2 工具系统 (tools/)

**架构特点**: 高性能枚举类型设计

```
tools/
├── types.rs           # Tool 枚举定义
├── registry.rs        # 工具注册表 (O(1) 查找)
├── middleware.rs      # 中间件栈
├── composable.rs      # 可组合工具
├── composition.rs     # 组合执行策略
├── executor.rs        # 统一执行器
├── schema_validator.rs # Schema 验证
├── version.rs         # 版本管理
├── versioned_registry.rs # 多版本注册表
├── template.rs        # 参数模板
├── external/          # 外部执行器
│   ├── python.rs
│   ├── nodejs.rs
│   └── docker.rs
└── algo/              # 算法工具
    └── ac_automaton.rs
```

**Tool 枚举设计**:
```rust
pub enum Tool {
    Native(NativeTool),
    Python(PythonTool),
    NodeJs(NodeJsTool),
    Docker(DockerTool),
    Wasm(WasmTool),
    Composed(ComposedTool),
}
```

**关键特性**:
- O(1) 工具查找（DashMap）
- 中间件栈（日志、指标、缓存、熔断、重试、超时）
- 多版本支持（语义化版本）
- Schema 验证（JSON Schema）

**架构特点**: 多类型插件统一管理

```
plugins/

    ├── batch/         # 批处理
    ├── classification/ # 分类
```

**插件类型支持**:
| 类型 | 隔离级别 | 执行方式 | 适用场景 |

| Docker | 容器隔离 | Docker API | 完全隔离 |
| WASM | 沙箱隔离 | wasmtime | 安全执行 |
