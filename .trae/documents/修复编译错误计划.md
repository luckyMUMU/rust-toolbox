## 修复编译错误计划

### 错误分析

当前有206个编译错误，主要分为以下几类：

#### 1. WorkflowError 方法缺失（约100+错误）
代码中使用了不存在的方法：
- `WorkflowError::execution()` → 应改为 `WorkflowError::tool()` 或 `WorkflowError::workflow_execution()`
- `WorkflowError::validation()` → 应改为 `WorkflowError::workflow_validation()` 或 `WorkflowError::ValidationError()`
- `WorkflowError::concurrency()` → 需要添加此方法
- `WorkflowError::backpressure()` → 需要添加此方法
- `WorkflowError::tool_not_found()` → 应改为 `WorkflowError::not_found()`
- `WorkflowError::serialization()` → 应改为直接创建 `WorkflowError::Serialization`

#### 2. ToolRegistry 方法缺失（约50+错误）
- `tool_registry.get_tool()` → 应改为 `tool_registry.get()`
- `tool_registry.execute_tool()` → 需要实现或使用 `tool.execute()`
- `tool_registry.validate_tool_params()` → 需要实现

#### 3. BasicToolRegistry 未定义（约20错误）
- 替换为 `ToolRegistry`

#### 4. DockerToolConfig 字段缺失（2错误）
- `container_name` 字段不存在于 DockerToolConfig

#### 5. 类型不匹配（约30错误）
- 各种类型转换问题

### 修复步骤

#### Phase 1: 添加 WorkflowError 缺失的方法
修改 `src/error/mod.rs`：
- 添加 `concurrency()` 方法
- 添加 `backpressure()` 方法
- 添加 `validation()` 方法（如果还没有）

#### Phase 2: 为 ToolRegistry 添加缺失的方法
修改 `src/tools/registry.rs`：
- 添加 `get_tool()` 别名方法（调用 `get()`）
- 添加 `execute_tool()` 方法
- 添加 `validate_tool_params()` 方法

#### Phase 3: 修复 BasicToolRegistry 引用
搜索并替换所有 `BasicToolRegistry` 为 `ToolRegistry`：
- `src/interfaces/tui/app.rs`
- 其他相关文件

#### Phase 4: 修复 DockerToolConfig
修改 `src/plugins/docker.rs`：
- 添加 `container_name` 字段到 `DockerToolConfig`，或
- 修改使用代码，移除对 `container_name` 的引用

#### Phase 5: 批量替换错误方法调用
使用搜索替换：
- `WorkflowError::execution(` → `WorkflowError::tool(`
- `WorkflowError::validation(` → `WorkflowError::workflow_validation(`
- `WorkflowError::tool_not_found(` → `WorkflowError::not_found(`
